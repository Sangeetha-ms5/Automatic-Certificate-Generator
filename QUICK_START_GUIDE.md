## 🔍 Troubleshooting

**Logo not showing?**
- Click "Upload Logo" button in header
- Select PNG or JPG file
- Refresh page to verify

**Can't select template?**
- Button disabled = no template uploaded yet
- Click "Upload Template" first
- Wait for preview to appear
- Then click "Select Template"

**Template disappeared?**
- Check browser cache not cleared
- Re-upload if needed (takes 10 seconds)
- Templates save automatically when uploaded

## 💾 Data Persistence

**Everything saves automatically to browser storage:**

| Data | Storage Key | Persistence |
|------|-------------|-------------|
| CMX Logo | `cmxLogo` | Permanent |
| Participation Template | `template_participation` | Permanent |
| Achievement Template | `template_achievement` | Permanent |
| Appreciation Template | `template_appreciation` | Permanent |
| Completion Template | `template_completion` | Permanent |
| Current Certificate | `certificateData` | Temporary |
| Admin Session | `adminAuth` | Session |

**Permanent = Survives refresh, navigation, browser restart**  
**Temporary = Only during current certificate generation**
